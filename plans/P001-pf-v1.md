## 3. 关键回归闭环

实现阶段按失败用例补齐了以下边界；规则的现行定义只见对应设计文档：

- 未知配置、managed/unmanaged 冲突、无意义的 search-space/granularity 组合；
- workspace 发现、声明 overlap、固定依赖误管理、不可投影 marker；
- Git/非 Git 快照范围、越界来源、named/default index 与带 hash URL；
- timeout、signal、输出截断、脱敏和测试支撑依赖改变目标图；
- 候选为空、来源故障、非单调、非确定和空间内无通过样本；
- 非宿主 cell 不执行、partial 报告 merge、重复 search 的 cell 替换语义；
- 报告覆盖、投影重新计算、手工篡改报告和源码漂移；
- workspace 多包 apply、TOML 注释、恢复日志与重复 apply。

原实施日志曾逐周期列出 000–073；这些细节已经由上述测试和 Git 历史保存，不再在计划中复制契约文本。

## 5. 未由本计划实机覆盖的环境

- 非当前 CPython minor；
- macOS/Windows 等非宿主 target 的真实执行；
- 私有 index 凭据与真实多宿主 merge；
- 远端大型项目的长时间 floor search。

这些路径拥有本地契约/adapter 测试，但 P001 没有把它们表述为实机兼容性证据。
